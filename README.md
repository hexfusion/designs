# Designs

Design documents published for review and reference. Each one describes a
system as it is designed or as it ships, with its diagrams.

## Documents

Documents are listed here as they are published.

## Layout

Topics sit at the root, and each document has its own directory under its
topic. The document is the README.md in that directory, with its diagrams
beside it.

## Changes

Every change lands through a pull request. The main branch takes no direct
pushes.
